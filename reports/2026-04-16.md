1. **OpenAI Agents SDK 重大更新**

💬 一句话说清楚：OpenAI 给 agent 开发套件加上了沙箱执行和原生 harness，让 agent 能跑更长时间、更安全。

🎯 为什么重要：之前 agent 跑代码要自己搭执行环境，现在 OpenAI 直接内置了，门槛低了一大截。

🔧 技术拆解：可以类比成给 CI/CD 加了一个内置的 Docker sandbox，原来你要自己配 runner，现在平台帮你搞定了。

🛠 实际落地：前端工程师可以直接用 Agents SDK 构建能执行代码的 AI 助手，不需要操心沙箱安全问题。

📎 信息源：https://openai.com/index/the-next-evolution-of-the-agents-sdk
